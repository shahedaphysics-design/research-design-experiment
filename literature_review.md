

# Literature Review

## Source 1: Logistic Regression

Logistic Regression is a commonly used machine learning method for binary
classification problems. It estimates the probability of an outcome and
classifies observations based on a probability threshold.

## Source 2: Linear Regression

Linear Regression models the relationship between independent variables and
a continuous dependent variable. Although it is mainly designed for
continuous outcomes, it can be useful for understanding relationships
between variables.

## Source 3: Machine Learning for Survival Prediction

Machine learning techniques can be used to identify patterns in passenger
data and predict survival outcomes. Variables such as age, gender,
passenger class, and fare can provide useful information for prediction.

## Source 4: Model Evaluation

Model evaluation metrics help determine how well a machine learning model
performs on unseen data. Metrics such as accuracy, precision, recall,
F1-score, and mean squared error can be used depending on the type of
prediction problem.
